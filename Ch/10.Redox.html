Redox Reactions

The term "Redox" is a combination of Reduction and Oxidation. These two processes always occur together—something cannot be oxidised unless something else is reduced.

1. Three Ways to Define Redox

In IGCSE Chemistry, you must be able to identify oxidation and reduction using three different definitions.

DefinitionOxidationReduction
1. OxygenGain of OxygenLoss of Oxygen
2. ElectronsLoss of ElectronsGain of Electrons
3. Oxidation NumberIncrease in NumberDecrease in Number

A. Oxygen Transfer (Simple)

Usually applied to simple reactions like burning magnesium or extracting iron.

2Mg + O₂ → 2MgO
Magnesium gains oxygen: It is Oxidised.
CuO + H₂ → Cu + H₂O
Copper Oxide loses oxygen: It is Reduced.
Hydrogen gains oxygen: It is Oxidised.

B. Electron Transfer (Ionic)

This is the most important definition for electrolysis and ionic reactions. Use the mnemonic OIL RIG.

OIL RIG
Oxidation Is Loss of electrons.
Reduction Is Gain of electrons.
Half-Equations Example (Electrolysis)

Consider the reaction: 2Na + Cl₂ → 2NaCl

  • Oxidation: Na → Na⁺ + e⁻ (Sodium loses an electron)
  • Reduction: Cl₂ + 2e⁻ → 2Cl⁻ (Chlorine gains electrons)

2. Oxidation States (Numbers)

An oxidation number (state) is a number assigned to an element that shows how many electrons it has lost or gained. This helps identify redox in complex equations where there is no oxygen.

Rules for Assigning Oxidation Numbers:
1. Elements by themselves (e.g., Mg, O₂, Cl₂) = 0
2. Simple ions (e.g., Na⁺, O²⁻) = Charge of the ion
3. Compounds: The sum of oxidation numbers is 0.
4. Oxygen is usually -2; Hydrogen is usually +1.

How to use Ox. Numbers:

  • If the number goes UP (e.g., -1 to 0), it is Oxidation.
  • If the number goes DOWN (e.g., +2 to 0), it is Reduction.

3. Agents: Oxidising & Reducing

This part often confuses students. Remember: An "Agent" does something to something else.

The Oxidising Agent
  • It oxidises the other substance.
  • To do this, it must take electrons from the other substance.
  • Therefore, the oxidising agent itself gets Reduced.
The Reducing Agent
  • It reduces the other substance.
  • To do this, it gives electrons to the other substance.
  • Therefore, the reducing agent itself gets Oxidised.

4. Testing for Redox (Important!)

You must memorise the color changes for two specific reagents used to test for oxidising and reducing agents.

Test Reagent Detects what? Color Change
Potassium Manganate(VII)
(KMnO₄)		 Reducing Agents Purple → Colorless
Potassium Iodide
(KI)		 Oxidising Agents Colorless → Red/Brown
Exam Tip:
If KMnO₄ stays purple, no reaction occurred. If it turns colorless (often called 'decolourised'), a reducing agent is present (like SO₂).
Note: In older exams, Acidified Potassium Dichromate(VI) was used (Orange → Green), but KMnO₄ is the primary test in the new syllabus.

5. Real World Examples

A. Displacement Reactions

A more reactive metal displaces a less reactive metal from its compound.

Zn(s) + CuSO₄(aq) → ZnSO₄(aq) + Cu(s)
  • Zinc: 0 → +2 (Oxidised/Reducing Agent)
  • Copper: +2 → 0 (Reduced/Oxidising Agent)
  • Color Change: Blue solution fades to colorless; reddish-brown solid forms.

B. Preventing Rusting

Iron rusts when exposed to Oxygen AND Water. It is an oxidation process.

  • Galvanising: Coating iron with Zinc. Zinc is more reactive, so it oxidises instead of the iron (Sacrificial Protection).
