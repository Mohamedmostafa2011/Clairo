Atomic Structure

This topic explores the building blocks of matter. We look at the subatomic particles that make up an atom, how they are arranged, and how this structure determines the chemical properties of elements.

1. Subatomic Particles

An atom consists of a central nucleus (containing protons and neutrons) surrounded by shells of electrons. The mass is concentrated in the nucleus, while the volume is determined by the electron shells.

2. Defining the Atom

Every element is defined by the number of protons in its nucleus. If the number of protons changes, the element changes.

Key Definitions (Memorize!):
  • Proton Number (Atomic Number, Z): The number of protons in the nucleus of an atom. It also equals the number of electrons in a neutral atom.
  • Nucleon Number (Mass Number, A): The total number of protons and neutrons in the nucleus.

Calculating Particles

For an atom represented as AZX:

  • Protons = Z (Atomic Number)
  • Electrons = Z (in a neutral atom)
  • Neutrons = A - Z (Mass Number - Proton Number)

3. Isotopes

Isotopes are atoms of the same element which have the same proton number but a different nucleon number.

This means they have the same number of protons and electrons, but a different number of neutrons.

Exam Tip: Properties of Isotopes
Isotopes of the same element have the same chemical properties because they have the same electronic structure (same number of outer electrons). However, they have slightly different physical properties (like density or mass).

Relative Atomic Mass (Ar)

The Average mass of naturally occurring atoms of an element on a scale where the carbon-12 atom has a mass of exactly 12 units. We calculate this using the abundance of isotopes.

4. Electronic Configuration

Electrons are arranged in shells (energy levels) around the nucleus. The shells fill up starting from the one closest to the nucleus.

The Filling Rule: 2, 8, 8
  • 1st Shell: Holds max 2 electrons.
  • 2nd Shell: Holds max 8 electrons.
  • 3rd Shell: Holds max 8 electrons (for IGCSE level).

Example: Chlorine (Proton number 17) has a configuration of 2, 8, 7.

5. The Periodic Table Structure

The arrangement of the Periodic Table is based directly on electronic structure.

  • Group Number (Vertical): Equals the number of electrons in the outer shell (Valence electrons). Group I has 1 outer electron.
  • Period Number (Horizontal): Equals the number of occupied electron shells. Period 3 elements have 3 shells.
  • Noble Gases (Group VIII/0): Have full outer shells, making them stable and unreactive.
